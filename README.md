# 📊 Superstore Sales Performance Dashboard

A comprehensive Power BI dashboard designed to analyze retail sales performance, profitability, regional distribution, and product category trends.

---

## 🖼️ Dashboard Preview

![Superstore Dashboard](dashboard.png)

---

## 💡 Key Metrics & Insights

* **Total Sales:** $2.30M
* **Profit Margin %:** 12.47%
* **Total Profit:** $286.40K
* **Total Quantity Sold:** 38K Units

### Key Findings:
1. **Sales by Category:** Technology generates the highest sales and profit compared to Furniture and Office Supplies.
2. **Regional Breakdown:** West Region leads overall sales ($725.46K / 31.5%), followed by East and Central regions.
3. **Ship Mode Preference:** Standard Class is the most preferred shipment mode.

## 🛠️ Tools & Technologies Used
* **Business Intelligence Tool:** Microsoft Power BI
* **Data Visualizations:** KPI Cards, Stacked Column Chart, Donut Chart, Map View, Bar Chart, Slicers
